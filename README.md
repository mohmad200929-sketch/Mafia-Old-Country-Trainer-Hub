## 🧭 Overview

Welcome to **Old Country Save Architect**, a 2026-era companion toolkit designed for players who want to explore the richly layered world of a certain early-1900s-inspired open-world crime saga from a different angle — the angle of *careful, deliberate, and reversible experimentation*.

## 🎯 What This Companion Actually Does

The **Old Country Save Architect** is best understood as a *profile-and-preset* layer. It does not replace your game, does not modify your installation permanently, and does not require you to surrender control of your save data. Instead, it introduces a curated set of toggles and presets that you can flip on and off like switches on a vintage control panel.

The result is a sandbox within the sandbox — a place to test what happens when a character has a little more stamina, a little more coin in the pocket, or a slightly different relationship with the world around them. Everything is logged, everything is reversible, and every preset is documented in plain language.

### 🌟 Signature Capabilities

- 🎛️ **Preset Profiles** — Curated bundles of tweaks for different play moods: Story Focus, Exploration Heavy, Resource Light, and Archivist Mode.
- 🧩 **Toggle Matrix** — Individual switches for granular control, each with a plain-English description and a rollback note.
- 🗂️ **Snapshot & Restore** — Save your current configuration as a named snapshot and restore it later with one action.
- 🔒 **Non-Destructive Defaults** — The tool ships with everything off. Nothing changes until you say so.
- 📜 **Change Ledger** — A human-readable log of every adjustment made during a session, exported as a text timeline.
- 🖥️ **Responsive Interface** — The control panel rearranges itself gracefully from small laptop screens to ultrawide monitors.
- 🌍 **Multilingual Support** — Interface strings available in a growing set of languages, with community contribution slots.
- ♻️ **Rollback Engine** — Every modification is paired with a matching reversal routine, tested on each release.
- 📦 **Portable Mindset** — Designed to run alongside the game without leaving permanent footprints in system folders.
- 🛡️ **Stability Guards** — Built-in warnings when a combination of toggles is known to conflict with the base experience.

## 🚀 Getting Started — The Slow, Thoughtful Way

This project deliberately avoids the frantic "one-command setup" culture. Instead, we encourage you to move through the following stages at a comfortable pace. The journey is part of the experience.

### Phase 1 — Orientation
1. Read this document in full at least once. Yes, all of it. The details matter.
2. Identify which of the **preset profiles** matches your intended play mood.
3. Decide whether you want a **snapshot-first** workflow (recommended) or a **live experimentation** workflow.

### Phase 2 — Preparation
1. Locate your existing game profile data and make a manual backup copy in a location you trust.
2. Confirm your Windows build is current and that your graphics drivers are stable.
3. Close any background utilities that could interfere with the companion's file-watching behavior.

### Phase 3 — Activation
1. Acquire the companion package through your chosen distribution channel.
2. Extract the contents to a dedicated folder — avoid mixing it with game install directories.
3. Launch the control panel executable and let the first-run wizard scan for compatible profiles.
4. Review the detected profile list and confirm the correct target.

### Phase 4 — Configuration
1. Start with **Archivist Mode** if you are new — it makes the fewest changes.
2. Use the **Toggle Matrix** to enable individual switches one at a time.
3. Watch the **Change Ledger** as you go; it narrates what each toggle does in real time.
4. Once satisfied, create a **named snapshot** so you can return to this exact configuration later.

### Phase 5 — Reflection
1. Play for a session and note how the experience feels.
2. Return to the control panel and adjust, or restore a previous snapshot.
3. Export your Change Ledger to a text file if you want a permanent record of the session.

## 🧰 Feature Deep Dive

### 🎛️ Preset Profiles Explained

Preset profiles are curated combinations that reflect common player intentions. They are not "easy modes" or "difficulty skips" — they are *lenses* through which the same world can be experienced differently.

- **Story Focus** — Reduces friction around repetitive tasks so narrative beats land with fewer interruptions.
- **Exploration Heavy** — Tilts the experience toward discovery, with toggles that favor movement and observation.
- **Resource Light** — Adjusts the economy of everyday items so that scavenging feels less punishing.
- **Archivist Mode** — The most conservative profile; it enables only documentation and logging features with no gameplay adjustments at all.

### 🧩 The Toggle Matrix

Each toggle is described with four fields: **Name**, **Effect**, **Reversal**, and **Stability Rating**. This four-field structure is intentional — it mirrors how a careful engineer documents a change before flipping a switch.

| Toggle Name | Effect Summary | Reversal | Stability |
|-------------|----------------|----------|-----------|
| Stamina Cushion | Adds a gentle buffer to endurance during long pursuits | Instant | 🟢 High |
| Coin Purse Drift | Slightly enriches incidental pickups | Instant | 🟢 High |
| Relationship Patience | NPCs react with slightly more tolerance | Instant | 🟡 Medium |
| Weather Pacing | Adjusts how quickly weather fronts move through | Instant | 🟢 High |
| Encounter Density | Modulates how often random events occur | Instant | 🟡 Medium |
| Ledger Verbosity | Increases logging detail in the Change Ledger | Instant | 🟢 High |

### 🗂️ Snapshot & Restore

Snapshots are named, timestamped bundles of your entire configuration state. You can keep as many as you like, and you can annotate each with a short note — for example, "Before experimenting with encounter density."

### 📜 Change Ledger

The Change Ledger is a plain-text timeline. Every toggle flip, every snapshot creation, and every restore event is recorded with a timestamp and a one-line description. It is your memory when your memory fails.

### 🌍 Multilingual Support

The interface ships with a base language pack and accepts community translations. Each language is stored as a simple structured file, and contributors are credited in the `CONTRIBUTORS.md` file. Right-to-left scripts are supported through a mirrored layout mode.

### 🖥️ Responsive Interface

The control panel is built with a fluid grid. On a compact laptop, it collapses into a single-column card layout. On an ultrawide display, it expands into a three-pane workspace with the Toggle Matrix on the left, the Change Ledger on the right, and the Profile Overview in the center.

### 🛡️ 24/7 Customer Support

The project maintains a rotating support presence across time zones. Whether you are troubleshooting a snapshot conflict at 3 AM or asking a translation question at noon, someone is generally around to help. Support covers setup questions, compatibility reports, and general guidance.

## 🧪 Testing & Quality Assurance

Quality is not a phase — it is a habit. The 2026 edition of Old Country Save Architect is validated through:

- **Unit Tests** for every toggle's effect and reversal routine.
- **Integration Tests** that simulate full profile lifecycles from first-run to snapshot restore.
- **Fuzz Tests** that feed malformed configuration files to the parser to ensure graceful degradation.
- **Regression Suites** that replay historical configurations to confirm no behavior drifts between releases.
- **Manual Play Sessions** conducted by volunteers who report qualitative impressions alongside quantitative metrics.

The testing philosophy is simple: *if a reversal routine cannot be demonstrated, the toggle does not ship.*
